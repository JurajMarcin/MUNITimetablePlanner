How to import timetable from IS?

Download the timetable in XML (Programmer) format, make sure to have 'include teachers' and 'include all seminar groups of the courses displayed'.

You can download it by right clicking the following link and selecting Save As: https://is.muni.cz/auth/rozvrh/zobraz/muj?format=xml&bv=&tyden=0&od=&do=&vcuc=1&seminare_vsechny=1&vybrat=1. It will download the timetable for the term you have currently selected in IS. If the selected term is not correct, go to the IS Timetables application and change the selected term using the menu at the top.

Then import the downloaded file using the 'Import IS XML' button.

How to use Timetable Planner?

You can change the priority of seminars (lower the number means higher priority). Overlaping seminars are ordered by priority. Lectures have the highest priority by default.

You can also hide lesson, you don't want to see. Hidden lessons can be displayed using show all checkbox in the page header.

Colour of the lesson is determined by its priority.
